# Security Policy

## Supported releases

Yalnızca en güncel `vX.Y.Z` kod sürümü ve güncelleyicinin seçtiği en güncel `audio-vX.Y.Z` ses sürümü desteklenir.

## Reporting a problem

Bir paketin özeti eşleşmiyorsa veya dağıtım hesabının ele geçirilmiş olabileceğini düşünüyorsanız dosyayı çalıştırmayın. Hassas ayrıntıları herkese açık issue içinde paylaşmayın; GitHub özel güvenlik bildirimi kullanılabiliyorsa bildirimi bu kanaldan gönderin, aksi halde depo yöneticileriyle doğrudan iletişime geçin.

Bildirimde Release etiketi, dosya adı, indirme zamanı ve hesapladığınız SHA-256 değerini belirtin.
